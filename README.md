# Vellire

Vellire is a Unicode typing studio. Choose a style from the library, try it in the app, or apply it as you type in compatible Linux apps.

[Project website](https://vellire.netlify.app/) · [Latest installers](https://github.com/Zenvired/vellire/releases/latest)

## Windows

Download the x64 setup executable and follow the installer. The installer may download Microsoft Edge WebView2. The app can style text inside Vellire.

## Linux

Download the x64 Debian package, open a terminal in your Downloads folder, and run:

```sh
sudo apt install ./vellire_0.1.5_amd64.deb
```

System-wide typing requires a running IBus session. On GNOME, Vellire can register Alt+S and Alt+T to start and pause styling.
